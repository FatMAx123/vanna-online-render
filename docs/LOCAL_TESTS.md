# Проверки 0.6.2 — короткие катсцены

Серверная симуляция проверяет автоматическое вступление, переходы всех пяти
уровней, таймер результатов, повтор после поражения, финал и пропуск одним
игроком. В онлайне больше нет story-состояния dialog или ожидания 2/2.
Полные offline-диалоги по-прежнему используются только одиночным/локальным режимами.

Подробные результаты в JSON рядом. Браузерные проверки работают с реальными
WebSocket-клиентами в локальном Chromium, не с опубликованным Render-сервером.
Кампания проверена через фикстуры, не полным ручным прохождением.
Публичную ссылку/поведение после нового deploy нужно проверить отдельно.
