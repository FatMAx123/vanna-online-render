# Ванна войны — Render Free

Онлайн-кооператив на двоих: общая очередь автоматически создаёт отдельные
комнаты. Никаких приглашений и кодов. Одиночный и локальный кооператив сохранены.

## Короткие катсцены онлайн — 0.6.2

Онлайн больше не останавливается на длинных диалогах и подтверждениях обоих:

- Вступление — 8 секунд, затем сразу бой без дополнительной сцены/шторки.
- Между уровнями — одна катсцена 5–6 секунд вместо post+pre диалогов.
- Итоги уровня автоматически закрываются через 3 секунды.
- После поражения — короткий экран, затем 4 секунды сюжета и автоматический повтор.
- Финал — 8 секунд, затем 3-секундный экран победы и завершение матча.
- Escape или Enter у любого игрока пропускает общую катсцену для обоих.
- Оба клиента получают кадр/таймер от сервера; нет отдельных таймеров или голосования.
- Полный сюжет и обычные диалоги одиночного/локального режимов сохранены.

Для уже созданного Render-сервиса: Manual Deploy → Deploy latest commit.
Автодеплой выключен, поэтому простого обновления вкладки недостаточно.
После статуса Live обновите игру у обоих игроков. Перезапуск завершает текущие матчи.

## Публикация без MCP

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/FatMAx123/vanna-online-render)

Кнопка открывает настройки публикации, а не уже запущенную игру.
Проверьте план **Free** перед подтверждением. Для закрытого репозитория
разрешите приложению Render доступ только к этому репозиторию.

1. Загрузите файлы этого проекта в корень репозитория GitHub.
2. В Render: New → Blueprint → выберите этот репозиторий.
3. Проверьте, что создаётся ОДИН Web Service с планом **Free**, затем подтвердите.
4. Дождитесь статуса Live. Откройте фактический адрес, который выдаст Render.
5. Откройте игру с двух устройств → «Онлайн» → дождитесь автоматического матча.

`render.yaml` содержит настройки. Не создавайте отдельный сервер на каждую
комнату. Не добавляйте базу данных или платные ресурсы для первого теста.
Не создавайте реплики: очередь и комнаты находятся в памяти одного процесса.

Если Blueprint недоступен: New → Web Service → подключите репозиторий.

| Поле | Значение |
| --- | --- |
| Runtime | Node |
| Region | Frankfurt |
| Branch | main (или фактическая основная ветка репозитория) |
| Root Directory | оставить пустым, если файлы в корне |
| Build Command | npm install --omit=dev --ignore-scripts && npm run build |
| Start Command | npm start |
| Plan | Free |
| Health Check Path | /health |
| Auto Deploy | Off — обновления вручную, чтобы не обрывать матчи |

Перенесите переменные из render.yaml в Environment. Render задаёт PORT и
RENDER_EXTERNAL_URL сам. Ввод адреса WSS в игре не нужен: клиент использует
свой домен и /online. Сервер допускает origin RENDER_EXTERNAL_URL.
При добавлении собственного домена явно задайте ALLOWED_ORIGINS списком
разрешённых HTTPS-origin через запятую.

## Настройки Free

- Для первого теста максимум **2 комнаты**, до 20 гостевых соединений.
  Это ограничение запуска, не гарантия производительности — нужен тест на Render.
- Состояние передаётся 10 раз/сек, бой считается 60 раз/сек.
- Сетка карты отправляется компактно в base64 вместо JSON-массива.
- Первое подключение ждёт до 90 секунд и повторяется автоматически.
- Нет искусственного пинга из внешнего сервиса для обхода сна Render.
- Бесплатный сервис может засыпать/перезапускаться. При перезапуске комнаты
  теряются; кампания не сохраняется. Это прототип, не production SLA.
- При обычном временном обрыве есть 20 секунд для возврата в тот же матч.

## VK Play

Сначала проверьте игру по ссылке Render. Затем добавьте в Render переменную
VKPLAY_GMRID со своим настоящим числовым ID проекта (это не секрет) и
перезапустите сервис вручную. /config.js генерируется сервером с этим ID.
Укажите HTTPS-URL игры из Render в кабинете браузерного проекта VK Play.
Проверьте реальный iframe, авторизацию, звук и fullscreen перед модерацией.
Игра не считается опубликованной в VK Play только из-за успешного запуска Render.
Гостевые игровые сессии не являются проверенными аккаунтами VK Play.

## Проверки разработчика

Node.js 24: npm install; npm run build; npm test; npm run test:rules.
Браузерные тесты требуют Playwright и Chromium отдельно. Локальные результаты
в docs/. Публичный запуск/лимиты Render проверяются после реального deploy.

Исходники не содержат API-ключей Render/GitHub. Не добавляйте их в репозиторий.
На сервере TRUST_PROXY включён только за управляемым прокси Render.
